# GanaPawk.iopr — NevePoint

**NevePoint** is a browser-based snowflake-catching game. Snowflakes fall from the top of the screen — click or tap them before they hit the ground to score points. Every missed snowflake costs a life; run out of lives and the game ends.

## How to Play

| Action | Effect |
|--------|--------|
| Click / tap a snowflake | Score points (value × current level) |
| Let a snowflake reach the ground | Lose one life |
| Reach the next point threshold | Level up — flakes fall faster |

Keyboard shortcut: **Space** or **Enter** starts / restarts the game.

## Running Locally

No build step required — open `index.html` directly in any modern browser.

```
open index.html
```
